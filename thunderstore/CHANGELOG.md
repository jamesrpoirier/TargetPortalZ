# Changelog

## 1.0.1

- Added Valheim 1.0 compatibility.
- Added an alphabetical, clickable named-portal list.
- Restored portal map icons on the new map API.
- Added unrestricted item teleporting and a configurable fast transition.
- Updated portal discovery for Valheim's sector-based portal collection.
- Fixed portal limits incorrectly blocking unrelated building pieces.
- Removed obsolete right-click favorites and stale build configuration.
